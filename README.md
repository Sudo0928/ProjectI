# 🛠️ Description
- **프로젝트 소개** <br>
  해당 프로젝트는 게임 <아이작>을 간단하게 모작하는 것을 목표로 시작한 프로젝트입니다. <br>
  짧은 시간동안 진행한 과제이기에 몬스터, 던전, 아이템 시스템 등 필수 구현 요소만 포함하여 작업을 진행하였습니다.
<br>
